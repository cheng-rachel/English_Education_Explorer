# 13 Taxonomy Rule

The Agent must not invent alternative labels for the same concept.

If a new value appears necessary during M1:
- do not silently add it;
- use “其他” temporarily where needed;
- report the proposed taxonomy change after M1.

This prevents taxonomy drift during rapid development.
